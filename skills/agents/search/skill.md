# Agent Web Search

Tra cứu thời gian thực dạng văn bản: thời tiết, tin tức, giá thị trường, bản đồ, lịch vạn niên, cung hoàng đạo, phim CGV, game.

## Danh sách công cụ
- `weather_search`: tra thời tiết (được đề nghị qua chat)
- `search_news`: tìm tin tức (được đề nghị qua chat)
- `get_market_data`: giá vàng/xăng/tỷ giá (được đề nghị qua chat)
- `get_cgv_movies`: lịch chiếu phim (được đề nghị qua chat)
- `get_epic_free_games`: game miễn phí (được đề nghị qua chat)
- `get_vannien_data`: lịch vạn niên (được đề nghị qua chat)
- `get_zodiac_data`: tra cứu cung hoàng đạo (được đề nghị qua chat)
- `vietnam_data_lookup`: tra cứu dữ liệu việt nam
- `map_route`: tìm đường đi
- `map_pois`: tìm địa điểm
- `search_products`: tra cứu giá sản phẩm (được đề nghị qua chat)
- `web_research`: tìm hiểu trên web
